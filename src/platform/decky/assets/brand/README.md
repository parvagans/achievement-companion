# Brand assets

- `github-invertocat-{black,white}.svg` are the official GitHub Invertocat SVG variants from the [GitHub Logo Brand Toolkit](https://brand.github.com/foundations/logo).
- `kofi-symbol.svg` is the official Ko-fi symbol SVG from the [Ko-fi Brand Assets](https://more.ko-fi.com/brand-assets) archive.

Keep the original artwork, proportions, and brand colors intact when using these files.
